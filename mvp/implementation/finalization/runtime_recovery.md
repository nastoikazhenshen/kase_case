# Восстановление авторского runtime — 22.10.2026

При устранении ошибки загрузки стандартного шрифта рабочий агент ошибочно удалил `@oai/artifact-tool` через workspace junction, ведущий в bundled runtime. Файлы проекта и архивные входы не затронуты. Lead остановил изменение зависимостей и восстановил исходный пакет.

Использован официальный архив **той же установленной версии 26.1020.11348** из URL, записанного штатным установщиком Codex. Проверены размер 508185082 байта и SHA-256 `56783021688bd77f575ba4705f4881e6b444ea9d3a01917ff23d4fa75b5be040`. Из архива извлечены только 212 исходных обычных файлов пакета; пути проверены на выход за каталог. Каждый восстановленный файл побайтово/по SHA-256 сопоставлен с архивом. Удалены только 14 точно идентифицированных пустых shim-файлов, созданных агентом, после проверки их содержимого.

Версия пакета после восстановления — 2.8.99. Генерация таблиц и штатный `render_slides.py` работают; слайды рендерятся из фактического PPTX, PDF-превью собирается из этих кадров. Приложение Streamlit от авторского runtime не зависит. Архив восстановления, внешние библиотеки и временные shim-скрипты лежат только в игнорируемом `local_validation/` и не входят в Git или handoff ZIP.
