# Локальные результаты

Каталог создаётся для офлайн-вывода и игнорируется Git. После восстановления evidence-pack и запуска `mvp/scripts/export_report.py` здесь могут появиться:

- `report.json` — локальный отчёт со связанным snapshot ID;
- `mvp_results.csv` — CSV-экспорт отчёта;
- `report.html` — HTML-версия отчёта;
- `mvp_results.xlsx` — необязательная локальная рабочая книга;
- `workbook_checks.json` и `workbook_preview*.png` — проверка и превью рабочей книги.

Эти файлы могут содержать значения из локального рыночного evidence-pack. Не добавляйте их в публичный репозиторий и не передавайте без отдельной проверки прав на распространение. В чистом клоне каталог может содержать только этот README или отсутствовать до первого локального экспорта.

Рабочая книга создаётся только после `report.json` командой `node mvp/scripts/build_workbook.mjs` в author runtime, где доступен `@oai/artifact-tool`. XLSX остаётся локальным deliverable.
