# Доказательства и воспроизводимость

Снимок строится командой `python -m mvp.src.build_snapshot`. Она проверяет SHA-256 каждого указанного локального артефакта, сохраняет каноническую сериализацию и публикует идентификатор снимка. Проверка не превращает источник в разрешённый для перераспространения.

## Границы публикации

| Категория | Где хранится | В публичном Git |
| --- | --- | --- |
| Код, схемы, манифесты, журналы без рыночных значений | `mvp/src/`, `mvp/implementation/`, эта документация | Допустимо как техническая документация |
| Сохранённые ответы KASE, HTML, DOM, скриншоты и извлечённые рыночные строки | `mvp/data/raw/`, `mvp/data/processed/`, `mvp/outputs/`, `mvp/mvp_screenshots/` | Игнорируются; только локально |

Указанное разделение основано на тексте футера KASE о необходимости письменного разрешения на копирование материалов. До отдельного подтверждения прав нельзя выгружать байты ответов, цитаты сообщений или котировки.

## Цепочка доказательств

1. `mvp/implementation/acquisition/evidence_manifest.json` связывает каждый включённый в снимок новый артефакт с URL, SHA-256, статусом времени получения и локальным путём. Внутренний `pack_manifest.json` отдельного ZIP также проверяет вспомогательные локальные материалы, не включённые в снимок.
2. `mvp/implementation/acquisition/provenance_corrections.md` фиксирует исправление ошибочно записанного хеша CLSGb15: старое значение сохранено как ошибка, фактические байты повторно проверены.
3. Отдельные повторные получения для официальных оценок и полного сообщения CLSGb11 сохранены как ревизии; исходные файлы не заменялись. Для исходных файлов без зафиксированного времени поле статуса прямо говорит, что mtime файловой системы не является временем получения.
4. `mvp/implementation/source_path_migration.csv` документирует разрешение старых относительных путей. `mvp/implementation/release_manifest.json` содержит только счётчики и ограничения, без рыночных значений.

Свежие публичные маршруты наблюдались как `/api/instruments/trade-info/{ticker}/`, `/api/instruments/bonds/{ticker}/`, `/api/indicators/market-valuations/` и страница сообщения KASE. Это наблюдение не является гарантией стабильности API и не даёт права обходить WAF или автоматизировать неразрешённые маршруты.
