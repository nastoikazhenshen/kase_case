# Методология расчётов

Сначала применяется область: только `VERIFIED_KZT_COUPON` и дневные наблюдения. Затем проверяется режим торгов для этой даты. Для ценовых показателей обязательны `price_view_status=VERIFIED` и `price_basis=CLEAN_PERCENT_OF_NOMINAL`. Для исторических показателей требуется сертифицированная или исторически опубликованная финальность.

Порядок причин блокировки детерминирован: область, тип наблюдения, режим, ценовая вкладка, ценовая база, неполная сессия, финальность. Поэтому сообщение `BLOCKED_PRICE_VIEW` не скрывает факт, что значения могут существовать в локальном файле: оно означает, что метод запрещает их использовать.

Базовая линия — медиана только предыдущих сопоставимых строк. Нулевой либо округлённый до нуля оборот не используется как знаменатель. Для даты без явного момента действует документированная ретроспективная политика конца дня `+05:00`; она не сертифицирует время закрытия торгов.

Сообщение эмитента используется только как ретроспективный контекст. Полное сообщение CLSGb11 содержит минуту публикации, но не отображает часовой пояс; до подтверждения часового пояса доступность для торгового решения принимается лишь со следующего дня по политике `+05:00`.
